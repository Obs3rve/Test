ABCOFIT Academy Site Setup v0.3

This companion plugin creates editable Gutenberg page content and adds dynamic course list shortcodes.

Use Tools > ABCOFIT Setup after the block theme is active.
Create missing pages only. Existing pages are never overwritten.
To add resource articles: Posts > Add New.
To add courses: Tutor LMS > Courses.
To change navigation: Appearance > Editor > Header.
