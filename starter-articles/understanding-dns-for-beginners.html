DNS stands for Domain Name System. It helps your device find the network address associated with a name such as example.com. When DNS is not working, the internet connection itself might still be fine, but websites can fail to load by name.

What happens when you enter a website address?

Your browser needs an IP address for the destination. It checks available local information and may ask a DNS resolver. That resolver uses cached results or finds the answer from other DNS servers. After receiving the address, your device can attempt to connect to the relevant service.

Why DNS matters in IT support

A user might say: The Wi-Fi is connected but I cannot open our company portal. This description does not prove DNS is the problem. Your job is to test whether the device has general connectivity and whether the failure affects name resolution, a single website or the entire connection.

A safe troubleshooting sequence

  • Confirm the exact error and which websites or applications are affected
  • Check whether the device has an IP address and a working network connection
  • Try a known website and compare with another device on the same network
  • Use nslookup to see how a DNS name is being resolved
  • Review approved DNS settings and escalate network-wide issues when needed

Useful Windows commands

Open Command Prompt and try ipconfig /all to inspect the current network configuration. The nslookup command can request a DNS lookup, such as nslookup example.com. The ping command can provide limited connectivity evidence, but some hosts block ICMP, so a failed ping alone is not proof a service is down.

Common mistakes

Do not change DNS servers on a managed work computer without authorisation. Do not assume every connection issue is caused by DNS. And avoid using public DNS settings as a quick fix if company policies require internal DNS for private services.
