A slow computer is a common helpdesk complaint, but there is no single fix. A useful support approach is to gather evidence and identify whether the slowdown affects one application, the entire system or a particular period of the day.

Step 1. Ask the right questions

When did the problem begin? Is it slow all the time or only during meetings? Does the same issue happen after a restart? Were any applications installed or updated recently? The answers help you narrow the scope before making changes.

Step 2. Check resource usage

Open Task Manager and review CPU, memory, disk and network activity. High usage may be temporary, for example during an update. If a particular app repeatedly consumes resources, capture the details and consider the application's requirements.

Step 3. Verify storage and updates

Check available disk space and whether Windows has pending updates or a restart. Low storage can affect updates and everyday performance. Follow the organisation's update policies rather than installing unapproved software.

Step 4. Look for clues

Review relevant Windows notifications and Event Viewer entries when appropriate. Note error times and repeat patterns. Do not treat every event log warning as evidence of the root cause.

Step 5. Document what you did

  • Record what the user reported and when it started
  • List the checks you performed and their results
  • Note any authorised changes or restarts
  • Explain whether the problem was resolved or escalated
  • Give the user a clear next step

What not to do

Avoid immediately resetting Windows, deleting files or installing so-called optimiser software. Such actions can disrupt work, remove data or create security problems. Backups and permissions matter, especially in a business environment.

A useful first-line support skill is knowing how to investigate safely. Accurate observations and clear notes are often as valuable as the final fix.
